## Текущее состояние

- Прод-БД: 2091 вино, эмбеддинги SigLIP2 (1152), YOLO-кроп этикетки. У 10 вин кропа нет, для них эмбеддинг по полному фото.
- Статика `static/wines`: 2091 полная бутылка, это те же фото, что и в БД.
- `owner_eval`: угадано с первой попытки 51 из 52 (set1 26/27, set2 25/25), медиана задержки около 150 мс, максимум около 1.9 с (первый запрос до прогрева).
- OCR-переранжир: `margin_min: 0.01`. Запускается только на почти полных ничьих. В каталоге 30 групп (61 вино) с побайтно одинаковыми фото, их различает только текст этикетки.
- API: есть только `POST /v1/eval/predict` → `{"slug"}` и `GET /health`.
