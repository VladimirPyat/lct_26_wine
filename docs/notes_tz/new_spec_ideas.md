ЛЦТ26 сканер вин
Можно разделить наш продукт на несколько частей.
1. Публичная часть - обязательная на хакатоне. Это интерфейс, куда можно загрузить фото или снять на камеру. Выдача строго ОДНОЙ марки с лучшим соответствием, либо "не найдено в базе, рекомендуем аналоги". Ссылки на основную страницу вина на сайте Заказчика. Кнопка "нашли то что искали". Эндпоинт для проверки картинок списком, совместимый с тестировочным скриптом заказчика. Если будет этот ИИ ассистент - тоже тут.
2. Личный кабинет. Регистрация с подтверждением возраста (например через VK или ГУ, пока тестовый логин пароль). Тут будет 
- история поиска,
- можно писать отзывы на вина, 
- сохранять в избранное, 
- получать ачивки,
- лучшая цена, ближайшие магазины на карте.
  Основная киллер-фича как я вижу - поиск в ближайших магазинах и "лучшая цена". Пока у нас нет общей базы - хотя бы какая то минимальная демка. Было бы круто показать какие то вымышленные магазины на виджете карте. Ну или хотя бы просто добавить кнопку "найти лучшую цену рядом с вами"
3. Админ-панель - для заказчика. Тут можно:
- добавлять новые вина,
- смотреть статистику, сколько найдено, сколько не найдено, сколько отметок "нашли то что надо"
- смотреть статистику по производителям, по геопозиции (для разегистрированных пользователей кто разрешит использовать геолокацию)
4. В будущем - личный кабинет для поставщиков.

*логика поиска вин*
- находим топ 5 по векторке
- если есть явный фаворит - сразу выдаем
- если близкие значения - запускаем ocr реранк
- ИТОГОВАЯ выдача: только один лучший кандидат
- если уверенность низкая - выдаем возможные аналоги. Ищем через ocr и/или через мультимодальную llm

*сомелье* - вижу его не просто как болталку. Если и делать - ассистента сайта, наподобие vivine.com
