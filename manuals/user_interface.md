# Веб-интерфейс

Что видит пользователь и как с этим работать. Запуск — [quickstart.md](quickstart.md#9-запуск-решения), устройство UI-слоя — [architecture.md](architecture.md#веб-интерфейс-stage-4).

Интерфейс открывается по адресу приложения: `http://127.0.0.1:8080/` (или `http://<IP-компьютера>:8080/` с другого устройства). Отдельного фронтенд-сервера нет — страницы отдаёт тот же FastAPI-процесс, что и API. Вёрстка адаптивная (сначала мобильная), все основные сценарии работают и без JavaScript.

## Навигация

Шапка на каждой странице: **Сканер** (`/`), **Каталог** (`/catalog`), **Мои вина** (`/me`), кнопка **Войти** (демо-вход, см. ниже). На телефоне те же пункты — в нижней панели.

## Сканер — `/`

«Узнайте вино по этикетке».

- **Включить камеру** — съёмка с камеры устройства; рамка-«прицел» подсказывает, где держать бутылку (отправляется весь кадр).
- **Загрузить фото** — выбор файла из галереи / с диска; на компьютере можно **перетащить файл** в область загрузки.
- **Распознать** — отправка фото. Допустимые форматы — JPEG, PNG, WebP, до 15 МБ (`config/product.yaml` → `upload`). Ошибки (пустой файл, не картинка, слишком большой) показываются на этой же странице.
- Подсказки «Как получить точный результат» и блок «Последние поиски» (из истории в браузере).

Камера на телефоне доступна только по HTTPS или на `localhost` (ограничение браузеров); по обычному `http://<IP>` работает загрузка фото из галереи.

## Результат поиска — `/result/{id}`

После распознавания открывается страница результата с уникальной ссылкой (её можно переслать; фото запроса хранится 10 дней). Три состояния:

| Состояние | Что показано |
|---|---|
| **Найдено** (высокая / средняя уверенность) | Фото бутылки из каталога, метка «Высокая уверенность» / «Средняя уверенность», карточка вина, кнопка **Подобрать аналоги** |
| **Низкая уверенность** | Та же карточка с меткой «Низкая уверенность — возможно, это не то вино» и блок аналогов по данным с этикетки |
| **Не найдено** | «Вино не найдено в каталоге», предложение посмотреть аналоги из каталога, кнопки **Уточнить в каталоге**, **Исходное фото**, **Сканировать ещё** |

Уверенность показывается словами, без процентов (пороги — `config/product.yaml` → `confidence`).

**Карточка вина:** название, производитель, цвет и оттенок, регион, сорт винограда, сладость, крепость, температура подачи, «Сочетается с» (блюда), рейтинг (бокалы; «Нет оценок», если рейтинга нет), описание, ссылка **Открыть на сайте** (страница вина на сайте «Своё Вино», если есть). Кнопки **В избранное** и **Моя оценка** (нужен демо-вход). **Исходное фото** — просмотр своего снимка с увеличением.

**Это то вино? Да / Нет** — отзыв о результате (пишется в `data/tmp/search_feedback.jsonl`). После «Нет» предлагается подобрать аналоги.

### Аналоги

| Ситуация | Как подбираются |
|---|---|
| Вино найдено, нажата **Подобрать аналоги** | Из базы: **тот же сорт винограда**, **другие винодельни**, само вино исключено; топ-5 по рейтингу. Ниже — подсказка «Для более точного подбора воспользуйтесь цифровым сомелье» |
| Вино не найдено / низкая уверенность | Только по тексту этикетки (OCR): если прочитан сорт винограда (в том числе латиницей у импортных вин — CABERNET SAUVIGNON → Каберне Совиньон) — вина этого сорта, топ-5 по рейтингу. Если на этикетке видно только первое слово сорта («КАБЕРНЕ» без «Совиньон») — вина всего семейства (Каберне Совиньон, Каберне Фран, …), чип фильтра «Каберне» |
| Сорт не определён или ничего не нашлось | «Аналог подобрать не удалось» + ссылка в каталог |

Применённые фильтры показаны чипами: клик по чипу убирает фильтр и открывает каталог. **Показать все (N)** — полный список в каталоге.

## Карточка вина — `/wine/{slug}`

Полная карточка вина из каталога и блок «Похожие в каталоге». Открывается из результатов, аналогов, каталога и «Моих вин».

## Каталог — `/catalog`

Все вина каталога, отсортированы по рейтингу. **Фильтры:** цвет, сорт винограда, регион, сладость, блюдо (значения — из справочников каталога). Активные фильтры — чипы с крестиком, **Сбросить все**; постраничная навигация **← Назад / Вперёд →**. Пустой результат — «По этим фильтрам вин не нашлось» и **Сбросить фильтры**.

## Мои вина — `/me`

Личный раздел без регистрации: **демо-вход** кнопкой **Войти** (без логина и пароля). Данные хранятся **только в этом браузере** (`localStorage`), на сервер не отправляются.

- **История** — прошлые поиски со ссылками на результаты;
- **Избранное** — вина, отмеченные «В избранное»;
- **Мои оценки** — выставленные оценки;
- **Выйти**, **Очистить мои данные**.

Раздел требует включённого JavaScript.

## Заглушки «Скоро»

На странице результата блок «Ещё возможности»: **Цифровой сомелье** (подбор вина к блюду; чипы блюд ведут в каталог с фильтром по блюду), **Найти в магазинах рядом**, **Чат** — пока не реализованы и помечены «Скоро».

## Для разработчиков

- Все данные UI получает из того же `ProductService`, что и JSON API `/api/v1/*` ([quickstart.md](quickstart.md#10-продуктовый-api-apiv1)); список JSON-эндпоинтов — Swagger `/docs`.
- Маршруты UI: `GET /`, `POST /search`, `GET /result/{id}`, `GET /result/{id}/photo`, `POST /result/{id}/feedback`, `GET /wine/{slug}`, `GET /catalog`, `GET /me`; статика UI — `/ui-static/…`, фото каталога — `/static/wines/{slug}.webp`.
- Шаблоны и стили — `src/web/`; тесты — `tests/web/`.
